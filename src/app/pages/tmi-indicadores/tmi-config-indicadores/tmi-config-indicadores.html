Indicadores del TMI

help_outline Cómo funciona

Cada indicador es una hoja del Excel. Su fórmula se escribe con letras: cada variable recibe una letra (A, B, C…) y se combina con + - * /, paréntesis y números. Ejemplo: Intervalo de sustitución = (A - B) / C. El resultado se calcula directo de TOTALIZADO3. Los inactivos no se calculan ni salen en el Excel.

Fórmula

1. Agregue las variables que usa el indicador: cada una recibe una letra (A, B, C…). Las variables se crean en la pestaña Variables. 2. Arme la fórmula haciendo clic en las variables, las operaciones y los paréntesis; cada clic agrega un bloque al final. Los bloques se pueden arrastrar para cambiarlos de lugar. Ejemplo: ( A − B ) ÷ C. La multiplicación y la división van antes que la suma y la resta: use paréntesis para agrupar. Una división entre 0 da NA ese mes.
