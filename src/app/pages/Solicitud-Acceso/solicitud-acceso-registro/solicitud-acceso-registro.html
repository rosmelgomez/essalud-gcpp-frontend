Solicitud de acceso

Completa estos pasos para registrar tu solicitud sin observaciones.

  1. Selecciona el tipo de trabajador.
  2. Busca por DNI para autocompletar tus datos.
  3. En caso que no se autocomple tus datos, agregalo manualmente.
  4. Para cabeza de red: selecciona solo Red.
  5. Para usuario de centro: selecciona Red y Centro.
  6. Ingresa correo institucional y descripcion.
