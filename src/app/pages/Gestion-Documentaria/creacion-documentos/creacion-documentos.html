Ayuda Memoria

Guía rápida de flujo para registrar y asociar correctamente los elementos en el sistema.

Tipo de Documento

Define las reglas y restricciones globales de los archivos:

  • Tamaño Máximo: Límite de tamaño en megabytes (ej: 10 MB).
  • Extensiones: Extensiones admitidas (ej: .pdf, .xlsx).
  • Aprobación: Determina si las versiones de este tipo requieren un flujo de aprobación formal.

Documento (Cabecera)

Es el contenedor lógico o carpeta en el sistema:

  • Código único: Identificador único (ej: Código de Informe o Traba).
  • Público/Privado: Define si será visible a otros usuarios.
  • Visibilidad Red: Si es público, puedes limitar el acceso solo a tu propia Red Asistencial o dejarlo para público general.

Versión de Documento

Corresponde al archivo físico subido en sí:

  • Documento Base: Debes seleccionar el documento lógico creado en el paso anterior.
  • Validación automática: El archivo se validará con las restricciones de tamaño y extensión del tipo correspondiente.
  • Aprobador: Si el tipo requiere aprobación, selecciona al aprobador asignado. El flujo iniciará en estado Pendiente.
